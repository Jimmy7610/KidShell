# Icons

Two kinds of icon live in KidShell:

* **Brand raster assets** - the MSIX tiles, splash screen and `KidShell.ico`.
  These are generated by `assets/generate-brand-assets.ps1` into
  `src/KidShell.App/Assets/`. `kidshell-mark-512.png` in this folder is the
  master copy of the mark.

* **App card icons** - vector XAML in `src/KidShell.App/Themes/AppIcons.xaml`,
  drawn at runtime by `AppIconPresenter`. No image files are involved.

Small chrome glyphs come from the Segoe Fluent Icons font that ships with
Windows and are referenced by glyph code, not copied here.

See `assets/README.md` for the full asset provenance.
